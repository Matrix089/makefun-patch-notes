A tiny Python program that writes one funny one-line patch note for a bug in real life, one line, to /output/entry.txt for make.fun's Real-Life Patch Notes: The Comedy Changelog bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
